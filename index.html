IT & Infrastructure

Before the games, and alongside them — nine years running a corporate Windows Server environment end to end. Sole administrator, 2 servers, 20–30 workstations.

IT Specialist Elfath Group Aug 2013 – Jan 2023

I designed the domain, built the servers, wrote the policies, held the perimeter, and supported every user on top of it. No team to escalate to — if it broke, it was mine.

🗂️ Active Directory

Built the domain from scratch — forest and domain setup, an OU tree mapped to the company's departments, security groups, and delegated rights. Replaced scattered local accounts with one managed identity per person.

🌐 DNS & DHCP

AD-integrated zones with forwarders and scavenging, plus DHCP scopes, reservations and options. Ended the static-IP collisions and the per-machine network fiddling.

📜 Group Policy

The policy baseline: password and lockout rules, desktop and security lockdown, mapped drives and printers, software deployment, targeted per OU with security and WMI filtering.

✉️ Exchange Server

Company mail brought in-house — mailbox databases, mail flow and connectors, distribution lists, shared mailboxes, transport rules, and OWA access.

🔐 Folder Security

A least-privilege share model on NTFS: department-scoped shares, ACLs granted to groups rather than individuals, and auditing so access to sensitive directories was traceable.

🩹 WSUS

Centralised patching with computer groups and staged approvals, so updates were piloted and tracked rather than left to each machine to sort out alone.

💽 WDS

Network OS deployment from a standard image. A new or wiped machine PXE-boots and comes back a working, domain-joined workstation — no manual install, no drift between desktops.

🧱 Hyper-V

Server roles run as virtual machines — sized, switched and checkpointed, so changes could be tested and rolled back instead of gambling with live services.

🛡️ MikroTik Firewall

The internet gateway. Per-user and per-group rules deciding who got out at all, and content and service filtering deciding what they could reach once they did.

🦠 Bitdefender GravityZone

Endpoint protection pushed to every machine from one console — policies by group, detections and quarantine monitored centrally, remediation handled from the same place.

On evidence: this environment was production, and its screenshots aren't mine to publish. So I'm rebuilding the stack as a documented Hyper-V lab — architecture, build scripts, and the policy baseline — and publishing that instead. In progress.
